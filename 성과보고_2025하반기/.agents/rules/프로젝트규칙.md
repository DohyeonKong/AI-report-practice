# 프로젝트 규칙 — 재정지원사업 성과보고

이 폴더에서 일하는 모든 작업(스킬 포함)은 아래 규칙을 따른다.

## 1. 폴더 규칙

| 폴더 | 용도 | 권한 |
|---|---|---|
| `resources/원본/` | 부서가 보낸 실적 자료(엑셀, 대시보드 캡처, 설문 원자료) | 읽기만. 수정·삭제 금지 |
| `resources/기준/` | 판단 기준 문서(공문, 사업계획서, 위원회 회의록) | 읽기만 |
| `resources/취합/` | collect-data 결과(요구사항, 팩트시트, 충돌 목록, 마스킹 사본) | 쓰기 |
| `templates/` | 보고서·요약·메일 양식 | 읽기만 |
| `reports/초안/` | write-report 결과(목차, 분석, 차트, 초안, 검토 기록) | 쓰기 |
| `reports/전달/` | deliver 결과(결재용 최종본, 요약, 메일, 예상 질의응답) | 쓰기 |

## 2. 숫자 규칙

- 보고서에 쓰는 숫자는 `resources/취합/fact_sheet.csv`에 있는 것만 쓴다.
- 예산은 천원 단위, 비율은 % 소수점 첫째 자리(사사오입), 비율끼리의 차이는 %p로 쓴다.
- 합계는 원자료의 합계 행을 믿지 않고 직접 다시 더한다.
- 단위과제 명칭은 사업계획서 명칭을 쓴다.

## 3. 사실 규칙

- 자료에 없는 사유·계획·날짜·담당자를 만들지 않는다. 근거가 없으면 `[담당부서 확인 필요]`로 둔다.
- 회의록에서 '재논의', '검토', '협의 후'가 붙은 항목은 결정이 아니다. 보고서에는 "검토 중(미확정)"으로만 쓴다.
- 자료끼리 숫자가 다르면 조용히 하나를 고르지 말고 `resources/취합/conflicts.md`에 남긴다.

## 4. 개인정보

- `resources/원본/`의 설문 원자료는 열 이름 외에는 읽거나 출력하지 않는다.
- 개인정보 처리는 `collect-data` 스킬의 `scripts/mask_pii.py`로만 한다.
- 보고서·메일에 성명, 학번, 연락처, 이메일을 쓰지 않는다.

## 5. 사람 확인 지점

각 스킬이 끝나면 결과를 5줄 이내로 요약하고 **멈춰서 사용자의 확인을 기다린다.**
확인 없이 다음 스킬로 넘어가지 않는다.

## 6. 문체

- 보고서: 개조식. □(대항목) → ○(중항목) → -(세부), 명사형 종결(~함, ~임).
- 과장 표현(획기적, 대폭 등)을 쓰지 않는다.
