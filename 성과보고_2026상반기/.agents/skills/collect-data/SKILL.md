# collect-data — 취합

## 입력
- `resources/기준/`: 공문(이미지), 사업계획서(PDF), 위원회 회의록(docx)
- `resources/원본/`: 실적 엑셀, 대시보드 캡처(PNG), 설문 원자료(CSV, 개인정보 포함)

## 출력 (`resources/취합/`)
| 파일 | 내용 |
|---|---|
| `requirements.md` | 제출 요구사항 표 + 체크리스트 |
| `source_notes.md` | 파일별 자료 메모와 의심 사항 |
| `<설문파일명>_masked.csv` | 개인정보를 가린 설문 사본 |
| `fact_sheet.csv` | 보고서에 쓸 모든 숫자(한 줄에 하나) |
| `conflicts.md` | 자료 간 충돌과 처리 결과 |

## 절차

### 1단계. 요구사항 뽑기 → `requirements.md`
1. 공문 이미지는 요약하기 전에 글자를 그대로 옮겨 적는다. 읽기 어려운 글자는 `[판독불가]`.
2. 다음으로 분류한다: 제출처, 기한, 제출 형식, 분량, 작성 방식, 필수 항목, 표기 규칙, 금지 사항, 독자별 산출물.
   공문의 '유의사항(※)'과 '붙임'까지 빠짐없이 본다. 붙임 양식은 `templates/`에 있다.
3. 회의록 항목을 '결정'과 '미결정(재논의·검토·협의 후)'으로 나눈다.
4. 기한이 여러 개면 가장 빠른 것부터 정렬한다.
5. 모든 항목에 근거(문서명, 항목 번호)를 붙이고, 끝에 체크리스트를 만든다.

### 2단계. 원자료 읽기 → `source_notes.md`
1. 파일 목록: 파일명, 형식, 작성 주체, 기준 시점.
2. 형식별 확인 사항
   - PDF: 표의 행·열을 유지하고 '(단위: …)' 문구를 함께 적는다.
   - 엑셀: 모든 시트를 연다. 단위 표기 셀, 합계 행, 수식, 비고 열을 확인한다.
     같은 열에서 다른 행보다 자릿수가 크게 다른 값 → '단위 혼재 의심'.
     % 열에 0~1 사이 값이 섞여 있으면 → '비율/퍼센트 혼재 의심'.
   - 이미지: 숫자와 함께 기준일, 기간, 축 범위를 적는다. 세로축이 0에서 시작하지 않으면 표시.
   - 한글(HWP): 직접 읽히지 않으면 사용자에게 PDF로 저장해 달라고 요청한다.
3. 자료마다 다른 명칭으로 부르는 같은 대상을 '명칭 대응표'로 정리한다.
4. 의심스러운 값은 고치지 않고 '의심 사항'에 적는다.

### 3단계. 개인정보 가리기 → `<설문파일명>_masked.csv`
1. 설문 파일은 첫 줄(열 이름)만 확인한다. 내용을 읽거나 출력하지 않는다.
2. 이 스킬 폴더의 스크립트를 실행한다.
   `python .agents/skills/collect-data/scripts/mask_pii.py "resources/원본/<설문파일>.csv" "resources/취합/"`
3. 출력되는 '치환 건수'와 '잔여 패턴(0이어야 함)'만 보고한다.

### 4단계. 팩트시트와 충돌 → `fact_sheet.csv`, `conflicts.md`
1. 열: `항목,값,단위,기준일,방향,출처파일,출처위치,변환,상태,메모`
   - 방향: 높을수록 우수 / 낮을수록 우수(예: 중도탈락률)
   - 상태: 확정 / 참고 / 충돌(확인 필요)
2. 단위를 통일하고(예산 천원, 비율 %), 바꾼 값은 '변환' 열에 계산식을 적는다.
3. 같은 값이 여러 자료에 있으면 대조한다. 기준일이 다르면 최신값을 확정, 나머지는 참고.
   기준일이 같은데 값이 다르면 '충돌'로 두고 사용자에게 묻는다.
4. 합계는 개별 값을 다시 더하고 사업계획서 총액, 회의록 언급 수치와 대조한다.
5. 설문은 마스킹 사본으로만 집계한다. 중복 응답, 결측, 범위 밖 값을 제외하고 제외 건수를 적는다.
   설문 만족도와 성과지표의 '교육만족도'가 같은 조사인지 확인한다.
6. `conflicts.md`: 무엇이 달랐는지 / 무엇을 채택했는지 / 근거, 그리고 '사람 확인이 필요한 항목'.

### 5단계. 멈추고 확인 받기
확정·참고·충돌 건수, 사람 확인이 필요한 항목을 5줄 이내로 보고하고 멈춘다.

## 검증 기준
- 모든 팩트에 단위·기준일·출처가 있다.
- 합계를 직접 검산했고 다른 자료와 일치한다.
- 마스킹 사본의 잔여 패턴이 0건이다.

## 웹(Gemini·ChatGPT)에서 쓸 때
- 파일을 대화에 직접 올리고, 각 출력 파일은 파일명을 제목으로 단 코드 블록으로 보여 준다. 사용자가 저장한다.
- 3단계(개인정보)는 웹에서 하지 않는다. 강사가 나눠 준 마스킹 사본을 쓴다.
