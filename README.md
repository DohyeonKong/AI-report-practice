# AI agent로 보고서 작성하기 — 실습 자료

| 폴더·파일 | 용도 |
|---|---|
| `따라하기_가이드.md` | 단계별 프롬프트와 저장 위치, 확인 체크리스트 |
| `성과보고_2026상반기/` | 1~2일차 따라하기 실습 프로젝트 (강사 시연과 같은 자료) |

프로젝트 폴더 구조: `.agents/`(규칙·스킬) · `resources/`(원본·기준·취합) · `templates/` · `reports/`(초안·전달)

대학명, 사업명, 수치, 인명은 모두 가상입니다.

한글(hwpx) 파일
- 위원회 회의록(`resources/기준/04_…회의록.hwpx`)은 한글 문서입니다. 한글에서 바로 열 수 있습니다.
- 결재용 최종본은 docx와 hwpx 두 가지로 만들어집니다(`reports/전달/`). 기관 양식에 붙여 넣을 때는 hwpx를 엽니다.
- hwpx 변환에는 Python 3.10 이상과 `pip install python-hwpx`가 필요합니다.
- 웹 AI(Gemini·ChatGPT)에 hwpx가 올라가지 않으면 한글에서 '다른 이름으로 저장 → PDF'로 저장해 올립니다.

안전 수칙
1. 실제 학교 자료, 학생·교직원 개인정보는 실습에 쓰지 않습니다.
2. `resources/원본/`의 설문 원자료는 웹 AI에 올리지 않습니다. 마스킹 사본만 씁니다.
3. AI가 쓴 숫자는 팩트시트와 대조하기 전에는 믿지 않습니다.
